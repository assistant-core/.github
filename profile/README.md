# Assistant Core

Build AI assistants that chat, talk and act: on the web, in messaging apps, on
ESP32 speakers and smartwatches. Streaming chat, realtime voice, knowledge,
memory and MCP tools on one platform.

[Website](https://assistantcore.com) · [Docs](https://docs.assistantcore.com) · [Voice API](https://docs.assistantcore.com/en/developers/voice-api)

## Open source

| Repository | What it is |
| :--- | :--- |
| [skills](https://github.com/assistant-core/skills) | Agent Skill and Claude Code plugin for managing your assistants from Claude, Codex, Cursor and other AI apps |
| [mcp-bash](https://github.com/assistant-core/mcp-bash) | Let your assistant run bash commands on your machine through a local connector |
